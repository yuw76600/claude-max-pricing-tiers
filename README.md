## Claude Max 的两个档次，差别在额度不在功能

Max 不是“解锁新功能”的套餐，它解锁的是额度。两档的权益清单是一样的：

- 用量是 Pro 的 5 倍或 20 倍（按档次选）
- 所有任务的输出上限更高
- 优先体验新功能
- 高流量时段优先访问
- Pro 已有的功能全部包含

区别只有一条：会话额度。Max 5x 是 Pro 的 5 倍，Max 20x 是 Pro 的 20 倍。你要是重度用户，这条区别就是全部。

还有个容易被忽略的点：**Max 目前只提供月付**。Anthropic 帮助中心写得很直接，没有年付选项，也就不存在“年付打折、折合下来每月只要多少”这种算法。想省钱只能从档次上想办法，不能从周期上想办法。

## 走第三方渠道订阅，先知道这几件事

这部分不是免责声明，是判断信息。

**它不是官方渠道。** 第三方评测明确写过：BeWild 是订阅辅助平台，不是 Anthropic 自己的销售入口。它帮你解决的是支付，不是授权。

**续费和到账不是 100% 稳定。** 有用户公开记录过自己的遭遇：三个月的订阅没能按期自动续费，另一笔新购两个月套餐虽然订单显示完成，账号却仍是免费版；后来客服恢复回复，两笔异常订单分别获得退款或退款方案。平台售后最终接手了，但期间的时间成本是真实发生的。

**额度宣传有过争议。** 有媒体报道过围绕 Max 套餐用量表述的集体诉讼。这不是说 Max 不能用，而是提醒你：任何“无限使用”的说法都别信，Anthropic 自己也写了有使用限额，并在 2025 年 8 月 28 日起对 Pro 和 Max 加上了每周用量上限，超出部分可以按标准 API 价格购买额外用量。

**官方渠道永远更干净。** 如果你手上有能正常扣款的海外卡，直接订阅官方，账号归属、续费、售后都没有中间环节。第三方代订的价值只在一种情况下成立：你确实付不出去这笔钱。

**1. Claude Max 有年付吗？**
没有。帮助中心写明目前只提供月度订阅。想降低单月成本只能看用不用得上，不能靠拉长周期。

不一定。官方说明移动端价格可能因应用平台而异，买之前对比一下网页端和 App 内购。

**3. 开了 Max 还会被限流吗？**
会。Max 有使用限额，5x 和 20x 指的是相对 Pro 的倍数，不是无限。

**4. 国内没有海外信用卡，最省事的路径是什么？**
两条路：App Store / Google Play 礼品卡内购，或者第三方代订平台。礼品卡走的是官方内购渠道，安全性更高但要折腾账号区域；代订平台更省事，代价是溢价以及对平台的信任成本。根据自己的时间成本选。

**5. Max 5x 和 20x 中间有别的档吗？**
没有。官方就这两档，$100 和 $200，二选一。
